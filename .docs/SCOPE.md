### 项目备注：

- 项目名称为 **video cat**，一个把长视频抽帧重渲染为轻量短视频、并分离出压缩音频，供多模态 AI 消费的 Windows 桌面工具。

**定位**

长视频超出多模态 AI 的上下文承载能力，直接投喂会占用大量上下文并诱发幻觉。工具将长视频按每秒随机抽帧重渲染为低分辨率短视频，同时把音频分离为独立压缩文件，两条通道分别投喂 AI，在压缩上下文的同时保留视觉与听觉信息，互为补充。

**边界**

- 输入：mp4 及 ffmpeg 可解容器；输出：重渲染短视频 + 独立音频 + 元数据 JSON。
- 仅做「压缩预处理」，不剪辑、不合成、不改变内容语义。
- 交互为单机单任务为主的本地 GUI，非批处理服务。

**目标平台**

- 交付物：Windows 11 x64 exe（GUI）。
- Linux（WSL）仅用于开发与后端逻辑验证，不作为交付平台。

**技术栈**

- 后端：Go。
- 桌面外壳：Wails v2（WebView2）。
- 前端：React + Fluent UI React v9，Win11 Fluent 风格。
- 媒体处理：ffmpeg / ffprobe 子进程（首次启动自动下载，优先 GPU 硬件编解码，回退 CPU）。

**非目标**

- 视频编辑 / 剪辑 / 转场；内容理解与摘要生成。
- 调用云端 AI 或上传视频；集成 ASR / 字幕转写。
- 跨平台（macOS / Linux）交付。

**性能取向**

GPU 硬件解码与编码优先（NVENC / QSV / AMF / D3D11VA），自动探测、失败回退 CPU；渲染支持以 Windows 为主。
