## 概述

<!-- 定位一句话，与 SCOPE.md 一致；非目标用于约束范围，SCOPE.md 已详述时只写引用。 -->

- **定位**：本地运行的命令行书签管理器，SQLite 存储，支持标签与全文检索。
- **阶段**：开发中
- **非目标**：浏览器同步、GUI（详见 `SCOPE.md`）

## 环境与运行

<!-- 环境类坑在本节用 ★ 标出，其余坑写进「约束与决策」。 -->

- **平台**：Windows 11 x64，本地运行
- **Shell**：PowerShell 7
- **运行时**：Python 3.12.4；依赖由 uv 管理，清单见 `pyproject.toml`
- **版本管理**：git；`main` 为稳定分支，功能在 `feat/*` 开发后合并
- **运行**：`uv sync` 后执行 `uv run bmk --help`
- **测试**：`uv run pytest`；核心契约用例在 `tests/test_store.py`
- ★ 数据库位于 `%APPDATA%\bmk\bmk.db`；测试通过 `BMK_HOME` 指向临时目录，不读写真实数据
- ★ 路径含空格或中文时加引号

## 结构

<!-- 目录树列处关键项，每项一行职责；数据流与依赖方向紧随其后。 -->

```
bmk/
├─ src/bmk/
│  ├─ cli.py        # 参数解析与输出格式化，唯一面向用户的入口
│  ├─ service.py    # 业务逻辑：增删改查、标签、检索
│  ├─ store.py      # SQLite 读写
│  └─ models.py     # 数据模型：Bookmark、Tag
├─ migrations/      # schema 迁移脚本，按序号执行
├─ scripts/
│  └─ import_html.py  # 从浏览器导出的 HTML 导入书签
└─ tests/
```

- **数据流**：命令行参数 → `cli` → `service` → `store` → SQLite；结果原路返回，由 `cli` 格式化输出。
- **依赖方向**：`cli → service → store`，`models` 为共享层。`store` 不依赖 `service`，`service` 不依赖 `cli`。

## 约定

<!-- 只写可执行的具体规矩；语言约定与 AGENTS.md 保持一致。 -->

- **命名**：模块与函数 snake_case，类 PascalCase
- **语言**：用户可见文本用中文；注释、日志用英文
- **错误处理**：`service` 抛出 `BmkError` 子类，`cli` 统一捕获并转为退出码
- **日志**：标准库 `logging`，默认 WARNING，`--verbose` 切换为 DEBUG

## 约束与决策

<!-- 每条写成「规则——原因」；属于技术选型的在前面加日期。只记改动后会引发连锁影响的内容。 -->

- 2026-06-25 检索用 SQLite FTS5，不引入外部搜索引擎——单文件、零部署，十万条以内性能足够
- schema 变更只追加新迁移，不修改已有迁移——已有用户的数据库依赖迁移顺序
- `import_html.py` 只解析 Netscape 书签格式——主流浏览器导出都用这一格式，无需逐个适配
